# ADR 0003: Rich for Console Rendering

## Context
A command-line tool requires readable, descriptive, and user-friendly console feedback. Plain stdout messages make it difficult to differentiate between successful operations, warnings, logs, and errors.

## Decision
We select the **Rich** library for printing, formatting, and logging output to the terminal console.

## Rationale
*   **Vibrant Output**: Supports easy markup for colors, emojis, styled fonts, progress bars, and tabulations.
*   **Unified Logger**: Integrates seamlessly with Python's standard `logging` library using the `RichHandler`.
*   **Developer Experience**: Allows us to structure output formatting via predefined style blocks instead of manual ANSI escape characters.

## Consequences
*   We use a single `Console` instance across the app.
*   We provide visually distinct logging levels: `info`, `success`, `warning`, `error`, and `debug`.
*   Users receive clear visual confirmation of operations (e.g. green checks for success, red crosses for errors).
